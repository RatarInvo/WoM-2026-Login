JWT authentication service

One secure entry point for your Notes App.

Register users, authenticate credentials, and issue the JWT used by the boards and notes services.

https://wom-2026-login.onrender.com/

Quick start

JSON requests and responses.

Use the token everywhere

After login, send the returned token to protected APIs with Authorization: Bearer <your-jwt>. The token expires after 30 days.

Authentication

Register, then log in.

POST/registerCreate a user

Request body

The password is hashed with bcrypt before it is stored.

{
  "username": "Albin",
  "password_hash": "password123",
  "role": "user",
  "email": "albin@example.com"
}

Response

{ "msg": "user created", "id": "user-uuid" }
200 OK
POST/loginIssue a JWT

Request body

{ "username": "Albin", "password_hash": "password123" }

Response

{
  "msg": "Login successful",
  "id": "user-uuid",
  "token": "eyJhbGciOiJIUzI1NiIs..."
}
200 OK401 on failure

User endpoints

Lookup routes for service integration.

GET/loginList users

Returns all users ordered by ID.

200 OK
[ { "id": "uuid", "username": "Albin", "role": "user" } ]
GET/login/:idGet one user

id is a user UUID. Returns 404 when no user exists.

200 OK404 Not found
{ "id": "user-uuid", "username": "Albin" }
GET/registerList registered users

Returns registered users ordered by ID.

200 OK
[ { "id": "uuid", "username": "Albin" } ]

Keep JWT_SECRET identical between this service and the Notes API. Never expose it or commit real environment credentials.
